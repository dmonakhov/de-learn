# de-learn

Tools for learning German.

Live site: https://dmonakhov.github.io/de-learn/

## A1

- [`A1/Verbkasten.html`](A1/Verbkasten.html): a trainer for the 30 most important A1 verbs.
  - Practise translation (German ↔ English, multiple choice or typed).
  - Practise present-tense conjugation, one form at a time or the whole table.
  - Uses spaced repetition with a 5-compartment flashcard box (Leitner system).

  It's a single self-contained HTML file: open it in a browser. Progress is kept in the browser's `localStorage`.
- [`A1/verbs.tsv`](A1/verbs.tsv): the same 30 verbs as plain text, with the English meaning, verb type
  (`reg` regular, `vow` vowel change, `irr` irregular, `mod` modal), an example sentence and all six present-tense forms.
